# Juno's Magic Tierlist Maker 🐮
## 🪄 Key Features

### 🏷️ Tier & Row Customization
- **Editable Tier Names**: Click directly on any tier label to rename it.
- **Custom Color Picker**: Each row has its own color swatch button with a native color picker to customize tier colors.
- **Reorder Tiers**: Move tier rows up (`▲`) or down (`▼`) with a single click.
- **Add New Tiers Anywhere**: Insert a new tier row below any existing row with the `＋` button.
- **Safe Row Deletion**: Deleting a tier (`✕`) automatically returns all images in that row back to the image staging pool so nothing is lost.

---

### 🖼️ Image Management & Drag-and-Drop
- **Multiple Upload Options**:
  - Click **Upload Images** to select multiple image files at once.
  - **Drag and drop** image files directly from your computer's desktop or file explorer onto the page.
- **Image Staging Pool**: Uploaded images stay in an organized unranked pool at the bottom until assigned to a tier.
- **Fluid Drag & Drop Interactions**:
  - Drag images from the pool into any tier.
  - Reorder images within a tier or move them between tiers with real-time drop placeholder preview.
  - Drag images back down into the pool to unassign them.
- **Quick Action Hover Button**: Hover over any image tile to reveal a quick `✕` button:
  - If in a tier: Returns the image back to the image pool.
  - If in the pool: Permanently removes the image from the workspace.

---

### 💾 Save & Load Configurations (.json)
- **100% Self-Contained Project Saves**:
  - Export your entire tierlist as a portable `.json` file (`Tier List DD-MM-YY.json`).
  - Saves all tier labels, colors, row order, image placements, and unranked pool items.
  - Images are encoded directly into the file (data URLs), meaning you can reopen the JSON on any computer without losing your images.
- **Smart Config Loader & Missing Image Detection**:
  - Load previously saved `.json` configurations instantly.
  - If any referenced images are missing, an interactive warning dialog appears listing the missing images, giving you the choice to cancel and upload them or proceed anyway. Please upload your images first and then load your .json file.

---

### ⬇️ Image Export (PNG)
- **High-Quality Canvas Rendering**: Accurately composites the tier list onto an HTML5 canvas, including row colors, wrapped label typography, row dividers, and image grids.
- **Export Modal Preview**: View a live preview modal of your rendered tier list before downloading.
- **One-Click Download**: Saves the finalized tier list directly as a timestamped PNG file (`Tier List DD-MM-YY.png`).
